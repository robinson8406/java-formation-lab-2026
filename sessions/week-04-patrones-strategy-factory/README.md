# Week 04 — Patrones: Strategy + Factory

**Fecha**: 2026-09-10 · **Paquete**: SOLID + TDD

## Objetivo

Aplicar los patrones **Strategy** y **Factory** para desacoplar comportamientos variables y facilitar la extensión y el testing independiente de cada estrategia.

## Contexto técnico

**Brecha QC atacada**: SOLID + TDD (77%), Patrones de diseño  
Los patrones Strategy y Factory son los más frecuentes en código Spring profesional. Dominarlos permite escribir código extensible sin tocar lo que ya funciona.
