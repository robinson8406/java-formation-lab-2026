Optimización de costos

Palancas de ahorro recomendadas

🖥️ VM con auto-shutdown

Impacto alto

Configura la VM con Azure Auto-Shutdown programado a las 20:00 y arranque manual solo en días con sesión o revisión de PRs. Esto reduce de 720 h/mes (24/7) a ~160 h/mes activas.

VM 24/7 (sin gestión) $36/mes → $8/mes

🗄️ PostgreSQL solo en JPA

Impacto alto

Provisionar el servidor PostgreSQL el 15 de octubre y eliminarlo (delete) el 05 de noviembre. No mantenerlo activo entre paquetes. En el paquete Spring Web (sem 6–8) se usa H2 in-memory sin costo.

PostgreSQL 5 meses $65 → $9 (4 sem)

🏷️ Azure Dev/Test Subscription

Impacto medio

Los beneficios de Visual Studio Enterprise o una suscripción Dev/Test aplican precios reducidos (hasta 55% en VMs Linux y bases de datos). Solo requiere que los recursos sean para uso no productivo.

Total sin descuento ~$100 → ~$55 USD

⚙️ Self-hosted vs Microsoft-hosted

Impacto medio

Con la VM B2s actuando como agente, los parallel jobs en Azure DevOps son gratuitos para orgs privadas. Cada Microsoft-hosted job adicional costaría $40/mes. Con 200 participantes ejecutando pipelines concurrentes, el ahorro es decisivo.

2 MS-hosted jobs $80/mes → $0/mes
